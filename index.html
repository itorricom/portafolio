Proyectos Destacados

Detalle técnico de implementaciones en producción, los problemas encontrados y cómo se resolvieron.

ENDE Corani · Portal de Proveedores

SICA — Sistema Integrado de Cotizaciones y Adquisiciones

Modernización del proceso de compras estatales

React 19 + NestJS + ERP
Portal web que digitaliza la invitación a proveedores, recepción de cotizaciones con documentación adjunta y reflejo directo en el ERP de la empresa eléctrica, reemplazando un proceso antes gestionado de manera manual.
Esquema de Separación de Servicios SICA
[Frontend: React 19] ──(JWT + PKCE)──> [Backend Público: NestJS] │ (Red interna privada) ▼ [API Interna] ──(SELECT FOR UPDATE)──> [ERP Corporativo]

Logros y Soluciones Técnicas

  • 01
    Separación de capas para proteger la base de datos: Diseñé una estructura de dos servicios: un backend público que atiende a los proveedores sin credenciales de la base de datos del ERP, y una API interna privada (sin puerto expuesto a Internet) que es la única que interactúa con esos datos.
  • 02
    Autorización validada por recurso: La API interna verifica en cada escritura que el usuario autenticado (mediante su JWT) sea realmente el dueño del registro que intenta modificar, evitando que un servicio perimetral comprometido pueda alterar datos ajenos.
  • 03
    Control de concurrencia en ERP sin documentación: Al analizar la base de datos heredada, identifiqué que la «invitación» y la «cotización» compartían la misma fila bajo distintos estados. Implementé bloqueos pesimistas (SELECT FOR UPDATE) dentro de transacciones en PostgreSQL para evitar condiciones de carrera cuando ingresan ofertas simultáneas.
  • 04
    Autenticación con Keycloak (OIDC): Configuré login con PKCE para la SPA en React, credenciales de servicio (Client Credentials) para la comunicación entre APIs y validación de tokens mediante JWKS con caché en memoria para no saturar al servidor de autenticación en cada petición.
  • 05
    Integración con gestor documental (Alfresco): Soporte para carga de documentación PDF con validación de firmas binarias (magic numbers en buffer, no solo la extensión del archivo) y control estricto de tamaño.
  • 06
    Entrega punta a punta de más de 10 historias de usuario: Flujo completo desde el login, listado de convocatorias, registro de cotización con adjuntos y visualización de resultados de adjudicación, probado contra un entorno de desarrollo real.
Stack utilizado:
React 19 Vite TanStack Router TanStack Query Tailwind CSS 4 shadcn/ui (Base UI) NestJS PostgreSQL Keycloak (OIDC) Alfresco Docker Compose GitHub Actions
Portal de Proveedores

silicec + auth-clean-gateway

Intermediación segura hacia ERP legado en PHP

React + NestJS + PHP ERP
Portal de convocatorias para proveedores externos, con un gateway de autenticación intermediario que valida y comunica las peticiones del frontend con un sistema ERP desarrollado en PHP.

Logros y Soluciones Técnicas

  • 01
    Acceso sin contraseña (Passwordless): Implementé un flujo de ingreso para proveedores sin usuario interno mediante combinación de NIT, correo y PIN temporal de un solo uso, respaldado por cookies de sesión httpOnly.
  • 02
    Resiliencia en despachos de correo masivo: Patrón de verificación previa de conectividad SMTP con reintentos antes de enviar lotes completos, junto con doble auditoría para distinguir problemas del servidor de correo de fallos individuales por destinatario.
  • 03
    Resolución de incidente con cookies en producción: Diagnóstico y corrección de un problema donde las sesiones se perdían silenciosamente: una cookie configurada como Secure era descartada por el navegador debido a que una variable de entorno en el build apuntaba a una URL interna HTTP en lugar del dominio balanceado en HTTPS. Se identificó analizando logs de peticiones y configuración de despliegue.

Sobre mí

Soy un ingeniero de software boliviano con foco en desarrollo full-stack. A lo largo de mi experiencia he trabajado bastante en conectar sistemas nuevos con arquitecturas existentes que llevan años funcionando y que rara vez cuentan con manuales o documentación actualizada.

Me siento cómodo trabajando tanto en la interfaz (haciendo que sea rápida y limpia con React) como en el backend y la base de datos (definiendo contratos de API en NestJS y entendiendo cómo se mueven los datos en PostgreSQL).

Valoro mucho el trabajo metódico: revisar logs con calma para encontrar la causa raíz de un bug, escribir código predecible y probar bien antes de tocar cualquier cosa en producción.

Cómo encaro el trabajo

Entender antes de reescribir
Un sistema antiguo suele tener años de reglas de negocio implícitas. Conviene investigarlo a fondo antes de intentar reemplazarlo.
Seguridad práctica
Aplicar conceptos claros: validar entradas, desacoplar servicios sensibles y dar solo los permisos necesarios.
Cuidado de producción
Los despliegues y migraciones de datos se planifican para evitar interrupciones o pérdidas de información.
